Part 2 — MAPLECAST_ASSIST: build + run + capture runbook
========================================================
Prereq: a NON-worktree-isolated session in the maplecast-flycast checkout (this
capture session is isolated to mvc-live-skins-quarters and its Write/Edit tools
refuse the maplecast-flycast shared checkout, so the source edit + rebuild must
run there). Toolchain already present (CMake + ninja + MSVC 2022 BuildTools +
vcpkg), confirmed by build-headless-win/_exec_build.log.

1) APPLY THE PATCH (from maplecast-flycast repo root):
     git apply tools/../.. # adjust: the patch lives at
     #   mvc-live-skins-quarters/tools/render-replica-poc/assist_poke.patch
     git apply /c/Users/trist/projects/mvc-live-skins-quarters/tools/render-replica-poc/assist_poke.patch
   (or apply the 3 hunks by hand with the Edit tool — autoselect.h, autoselect.cpp, emulator.cpp)

2) REBUILD (incremental; ~1 obj recompile + relink):
   - Ensure NO flycast.exe is running (else LNK1104 "cannot open file flycast.exe").
   - From build-headless-win, in an MSVC-env shell (vcvars64):  ninja flycast.exe

3) RUN THE RESIM WITH ASSISTS (adds MAPLECAST_ASSIST to the proven recipe):
     cd /d C:\Users\trist\projects\maplecast-flycast\build-headless-win
     set MAPLECAST_AUTOSELECT_MENUNAV=1
     set MAPLECAST_AUTOSELECT=44,42,16;23,49,52
     set MAPLECAST_ASSIST=0,2,2;1,0,2        <-- tape 59603897 assist_p1=[0,2,2] assist_p2=[1,0,2]
     set MAPLECAST_MOVIE_IN=C:\Users\trist\projects\maplecast-flycast\build-headless-win\movie_fresh_1714.txt
     set MAPLECAST_MOVIE_GAMEFRAME=1
     set MAPLECAST_MIRROR_SERVER=1
     set MAPLECAST_SERVER_PORT=7300
     set MAPLECAST_CONTROL_PORT=7311
     flycast.exe C:\roms\roms\mvc2.gdi
   Expect in stdout (read-back confirmation the coordinator asked for):
     [assist] target P1=0,2,2  P2=1,0,2
     [assist] readback slots0/2/4=0/2/2  1/3/5=1/0/2

4) CAPTURE THE FULL MATCH (fixed window; ZCST-only so 1 msg == 1 game frame):
     node C:/Users/trist/projects/mvc-live-skins-quarters/tools/render-replica-poc/capture_mirror_full.mjs \
       --url ws://127.0.0.1:7300/ \
       --out C:/Users/trist/projects/maplecast-flycast/build-headless-win/render_ta_wire_full.zcst \
       --max-frames 8500 --end-grace 300 --idle-ms 30000
   With correct assists the divergence at the first assist (~battle-frame 297) is
   gone, so the match should track toward the real 0-2 ending and the server should
   emit {"type":"match_end"} at the KO -> the capture stops on "match_end + grace".

5) SPOT-CHECK:
     node C:/Users/trist/projects/mvc-live-skins-quarters/web/tapecanvas/render_ta_wire.mjs \
       --mirror C:/Users/trist/projects/maplecast-flycast/build-headless-win/render_ta_wire_full.zcst \
       --frames 0,3000,6000,last --outdir <dir>
